# SMART TRADE
Transforme as trocas com aldeões em uma experiência mais inteligente, flexível e fiel ao vanilla. O SMART TRADE permite escolher quais recursos ficam disponíveis nos comércios, adicionando ofertas extras para diferentes profissões sem substituir, remover ou alterar as probabilidades das ofertas originais. Sua interface limpa, em estilo vanilla, é integrada ao Mod Menu e mantém todas as escolhas salvas entre as sessões.

O SMART TRADE existe para ampliar as possibilidades do comércio sem descaracterizar o sistema do Minecraft. As novas ofertas são acrescentadas depois das trocas vanilla e ficam disponíveis para aldeões novos ou já existentes, preservando progressão, demanda, descontos, reputação, cura, reabastecimento e demais mecânicas originais. Além dos comércios configuráveis, opções globais oferecem pequenos ajustes de qualidade de vida para tornar a sobrevivência mais prática e previsível.

## Recursos pensados em jogabilidade
|![space](https://cdn.modrinth.com/data/cached_images/379e1655ce7c438cd194b1260d0a309bdc5bc4ef_0.webp)|![space](https://cdn.modrinth.com/data/cached_images/b6f434fab7f5b844b77234dbe5352e9b8e79090b_0.webp)|
| --- | --- |
| Compatibilidade | Adiciona ofertas extras após a geração vanilla, sem disputar espaços, probabilidades ou sorteios originais. |
| Adaptação | Aplica as ofertas em aldeões novos e existentes, preservando descontos, demanda, progressão e reabastecimento. |
| Informações | Integra-se opcionalmente ao Jade para exibir reputação, curas e reabastecimentos do aldeão observado. |
| Reputação | Permite considerar sua reputação como máxima com todos os aldeões sem apagar os dados reais. |
| Velocidade | Mantém Velocidade das Almas ativa no Nether e normaliza o movimento sobre blocos de almas nas outras dimensões. |
| Altura | Padroniza a altura de cogumelos gigantes cultivados com pó de osso sobre nicélio carmesim ou distorcido. |
